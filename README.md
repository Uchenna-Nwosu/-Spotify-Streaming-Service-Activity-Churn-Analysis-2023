# -Spotify-Streaming-Service-Activity-Churn-Analysis-2023

This project analyzes user activity and churn patterns across 8,000 Spotify users to understand how subscription type, listening behavior, device usage, age, country, and skip behavior relate to retention.

The analysis was completed in Microsoft Excel and presented through an interactive dashboard using PivotTables, PivotCharts, KPIs, and slicers.

Business Objective

The objective of the project was to answer questions such as:

What is the overall churn rate?

Which subscription plans show the highest churn?

Which devices are most commonly used?

How does listening behavior vary across subscription types?

Which customer groups show stronger retention or higher churn?

How do skip rate and listening time relate to user activity?

Which segments may require stronger retention strategies?

Key Findings

1. Overall Churn

The dataset contains 2,071 churned users out of 8,000, giving an overall churn rate of approximately 25.89%.

This means roughly one in four users in the dataset had churned.

2. Subscription Type and Churn

Churn rates by subscription type were:

Family — 27.52%

Student — 26.19%

Premium — 25.06%

Free — 24.93%

Family users recorded the highest churn rate, while Free users recorded the lowest among the four plans.

3. Average Listening Time by Subscription Type

Average daily listening time remained relatively close across subscription plans:

Premium — 155.52 minutes

Free — 155.00 minutes

Student — 154.49 minutes

Family — 151.04 minutes

Premium users recorded the highest average listening time, while Family users recorded the lowest.

4. Skip Rate by Subscription Type

Average skip rates were:

Student — 30.29%

Free — 30.09%

Family — 30.03%

Premium — 29.66%

Premium users had the lowest average skip rate.

5. Device Usage

Desktop was the most common device in the dataset.

Desktop — 2,778 users

Web — 2,623 users

Mobile — 2,599 users

Churn rates by device were:

Mobile — 26.89%

Desktop — 25.74%

Web — 25.05%

Mobile users recorded the highest churn rate of the three device groups.

6. Country Distribution

Australia had the largest user count in the raw dataset with 1,034 users, closely followed by the United States with 1,032 users.

Country-level churn rates varied, with Pakistan and Germany among the higher-churn groups.

Recommendations

Prioritize Family-plan retention

Family users recorded the highest subscription-level churn rate.

Investigate Mobile-user churn

Mobile users had the highest device-level churn rate.

Study engagement beyond listening time

Listening-time differences between subscription plans were relatively small, suggesting that churn may depend on additional behavioral or product factors.

Use skip behavior as a supporting engagement signal

Premium users had the lowest skip rate, which may indicate stronger content satisfaction.

Segment retention campaigns

Retention strategies should be tailored by subscription type, device, age group, and country instead of relying on one broad approach.

Conclusion

The analysis shows an overall churn rate of approximately 25.9% across 8,000 Spotify users.

Family-plan users recorded the highest subscription-level churn rate, while Mobile users had the highest churn rate by device. Premium users showed relatively strong engagement through the highest average listening time and the lowest skip rate.

The dashboard provides an interactive view of user behavior and churn patterns that can support more targeted customer-retention strategies.
